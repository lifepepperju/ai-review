🔍 AI Review セットアップ手順（社内配布版）

このZIP／リポジトリには2つの機能が入っています。必要な方（両方でもOK）だけセットアップしてください。所要時間はどちらも5分ほどです。

A. Claude CodeスキルClaude Codeを使っている人向け
「レビューコメントを反映して」と話しかけるだけで、AI Reviewで付けたコメントを読み取って修正・書き戻しをしてくれます。
B. 右クリック連携（AI Review.app）Mac・cmux／Finderを使っている人向け（Windows不可）
HTMLファイルを右クリック →「このアプリケーションで開く」から、ブラウザでページを見ながらコメントを残せます。

A. Claude Codeスキルの導入

1スキルフォルダをコピーする

このリポジトリの中の skills/ai-review フォルダを、まるごと以下の場所にコピーします。
  • コピー先: ~/.claude/skills/ai-review/
  • ターミナルを使う場合:
cp -r skills/ai-review ~/.claude/skills/ai-review
既に ~/.claude/skills/ai-review がある場合は上書きでOKです。

2Claude Codeを再起動する

一度 Claude Code を終了して開き直すと、スキルが読み込まれます。
会話の中で「ai-reviewのコメントを反映して」のように話しかけると起動します。

B. 右クリック連携（AI Review.app）の導入

はじめる前に（前提）

  • Mac であること。 Windows では使えません。
  • Node（ノード）が入っていること。 入っていなくても、手順2でインストール方法を案内します。
  • このリポジトリ（またはZIP）を、分かりやすい場所に置いておく（例: 書類フォルダ）。
    ⚠ セットアップ後にこのフォルダを移動・名前変更しないでください（場所がズレると動かなくなります。動かした場合は手順3をもう一度やればOK）。

1フォルダを開く

このリポジトリ直下の macos フォルダを開きます。
この中に install.command というファイルがあります。

2Node が入っているか（入っていなければ入れる）

手順3を実行して「Node が見つかりませんでした」と出た場合だけ、ここに戻ってください。

  • かんたんなのは https://nodejs.org/ を開き、LTS（左側の推奨版）をダウンロードしてインストール。
  • Homebrew を使っている人は、ターミナルで brew install node でもOK。
入れ終わったら手順3に進みます。

3インストーラを実行する

install.command を 右クリック →「開く」 を選びます。

⚠ 必ず「ダブルクリック」ではなく「右クリック →開く」でください。初回はMacが「開発元を確認できません」と警告しますが、右クリックから開くと出てくる「開く」ボタンを押せば進めます（ダブルクリックだとブロックされます）。

黒い画面（ターミナル）が開き、自動でセットアップが進みます。
✓ 組み立て完了 と表示されれば成功です。続いてシステム設定が自動で開きます。

4フルディスクアクセスを許可する（いちばん大事）

自動で開いた 「プライバシーとセキュリティ → フルディスクアクセス」 の画面で:

  • 左下あたりの ＋ を押す
  • 開いたフォルダ（アプリケーション）から 「AI Review」 を選ぶ
  • スイッチを ON にする
⚠ この許可をしないと、ファイルを開いても何も起きません（無反応）。必ずONにしてください。

使い方（右クリック連携）

✓HTMLを開いてレビューする

  • cmux や Finder で、レビューしたい HTMLファイルを右クリック
  • 「このアプリケーションで開く」→「AI Review」 を選ぶ
  • ブラウザが開き、ページ上で気になる箇所にコメントを残せます
  • ブラウザのタブを閉じると、レビュー用のサーバーは自動で終了します
💡 一覧に「AI Review」が出ないときは「その他…」や「すべてのアプリケーション」を選ぶと出てきます。

うまく動かないとき

  • 開いても何も起きない → 手順4のフルディスクアクセスがONか確認。
  • フォルダを移動・名前変更してしまった → 手順3（install.command を右クリック→開く）をもう一度実行。
  • エラーの中身を見たい → ~/Library/Logs/ai-review.log にログが残ります。
  • それでも解決しないときは、このログを添えて宇佐見さんに連絡してください。
